Configurar APIs

Como Configurar suas APIs

Para configurar suas APIs no One's Brothers, siga estes passos:

1. Edite o arquivo .env

Localize o arquivo .env na pasta do projeto. Se não existir, copie o arquivo .env.example e renomeie para .env.

2. Adicione suas chaves

Adicione suas API keys seguindo o formato mostrado abaixo. Substitua "sua_chave_aqui" pela sua chave real.

Exemplo de Configuração (.env) 
# APIs principais já suportadas pelo bot
OPENAI_API_KEY=sua_chave_openai_aqui
ELEVENLABS_API_KEY=sua_chave_elevenlabs_aqui

# APIs adicionais para futuras integrações
ANTHROPIC_API_KEY=sua_chave_anthropic_aqui
GOOGLE_API_KEY=sua_chave_google_aqui
HUGGINGFACE_API_KEY=sua_chave_huggingface_aqui
REPLICATE_API_TOKEN=sua_chave_replicate_aqui
COHERE_API_KEY=sua_chave_cohere_aqui
STABILITY_API_KEY=sua_chave_stability_aqui

# Configurações do bot
VOICE_NAME=callum

Solução de Problemas

  • Verifique se o arquivo .env está na pasta raiz do projeto
  • Certifique-se de que não há espaços antes ou depois do sinal de igual
  • Reinicie completamente o bot após adicionar novas chaves
  • Verifique se a chave da API está correta e ativa

  • Confirme se a API key está correta no site do provedor
  • Verifique se sua conta tem créditos suficientes
  • Alguns provedores requerem ativação manual da API
  • Verifique se há limitações de região na sua conta

  • Reinicie completamente o processo do bot
  • Verifique se não há arquivos .env duplicados
  • Confirme se o bot está sendo executado da pasta correta
  • Algumas APIs podem precisar de configuração adicional no código
